【Windows11】更新エラー 0x800f0993 / 0x800f0989 / 0x80070306 の直し方

※本記事には広告（アフィリエイトリンク）が含まれます

結論：マイクロソフトも認めた不具合で、自動の修正が配信されています。ネットにつないだまま再起動し、更新プログラムのチェックをしましょう。

おすすめアイテム

外付けSSD 1TB
バックアップ用
Amazonで見る

1. エラーコードを確認

設定 › Windows Update › 更新の履歴 を開き、11月の更新に上の3つのコードが出ているか確認します。

2. ネットにつないだまま再起動

マイクロソフトが自動の修正を配信しているので、インターネットにつないだままパソコンを再起動します。

3. 更新プログラムのチェック

修正が届けば、11月の更新が自動でインストールされます。

4. トラブルシューティング

設定 › システム › トラブルシューティング › その他のトラブルシューティング ツール › Windows Update › 実行する
