【PS5】「最新のシステムソフトウェアをインストールしてください」の直し方｜NP-102944-0 / CE-108889-4

※本記事には広告（アフィリエイトリンク）が含まれます

結論：まず本体をアップデート。失敗するならルーターとPS5を再起動し、それでもダメならUSBを使ってセーフモードからアップデートしましょう。

おすすめアイテム

USBメモリ 64GB
PS5のアップデートファイル用
Amazonで見る

対象のエラーコード

NP-102944-0 / NP-102945-1 / NP-102946-2 / NP-102947-3 / CE-108889-4 / WS-116328-1

1. 本体をアップデート

設定 › システム › システムソフトウェア › システムソフトウェアアップデートと設定 からアップデートします。

2. ルーターとPS5を再起動

通信が不安定だと失敗しやすいので、ルーターとPS5を再起動してからもう一度試しましょう。

3. USBでアップデート

  1. パソコンで更新ファイルをダウンロード
  2. USB（FAT32かexFAT）に「PS5」フォルダ、その中に「UPDATE」フォルダを作って保存（フォルダ名は半角大文字）
  3. セーフモードで起動し、「USBストレージ機器からアップデート」を選ぶ

4. ゲームもアップデート

「最新のアップデートファイルをインストールしてください」と出たら、ゲームを選んでオプション › アップデートを確認 を実行します。
