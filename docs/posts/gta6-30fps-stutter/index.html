【GTA6】カクつく・重いのは故障？30fpsの真実と、なめらかにする3つの方法

※本記事には広告（アフィリエイトリンク）が含まれます

結論：GTA6はPS5・PS5 Proともに30fpsで、パフォーマンスモードはありません。テレビをゲームモードにして、アップデートとキャッシュ消去を試しましょう。

おすすめアイテム

ゲーミングモニター 4K 120Hz
PS5の映像をなめらかに
Amazonで見る

1. 30fpsは仕様

GTA6はPS5もPS5 Proも30fpsで動きます。パフォーマンスモードはないので、故障ではありません。

2. テレビをゲームモードに

テレビの映像モードを「ゲーム」に、倍速機能（なめらか機能）をオフにすると、操作の遅れが減ってなめらかに感じます。

3. 最新にしてキャッシュを消去

ゲームと本体をアップデートしたら、セーフモードで「キャッシュを消去してデータベースを再構築する」を実行します。セーフモードは、電源ボタンを長押しして2回目のピッで指を離すと起動できます。
