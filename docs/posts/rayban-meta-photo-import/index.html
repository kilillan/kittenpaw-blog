【Ray-Ban Meta】写真がスマホに転送できない時の直し方｜インポートできない5つの対処法

※本記事には広告（アフィリエイトリンク）が含まれます

結論：まずMeta AIアプリのギャラリー横の［インポート］をタップ。直らなければWi-FiとBluetooth、写真のフルアクセス、自動インポートの条件を確認しましょう。

おすすめアイテム

Ray-Ban Meta（Gen 2）
AIグラス本体
Amazonで見る

1. 手動でインポート

Meta AIアプリでグラスを開き、ギャラリーの横にある［インポート］をタップします。

2. Wi-FiとBluetoothを確認

写真の転送にはWi-Fiを使います。スマホのWi-FiとBluetoothをオンにして、グラスの近くで転送しましょう。ネットワークへの接続確認が出たら「接続」をタップします。

3. 写真へのアクセスを許可

スマホの設定 › アプリ › Meta AI › 写真 を「フルアクセス」にします。

4. 自動インポートの条件を確認

  • グラスの電源はオンのまま
  • ケースに入れるか、つるを閉じる
  • スマホのBluetoothとWi-Fiはオン
  • バッテリーは30%以上がおすすめ

5. アップデートと別のネットワーク

アプリとグラスを最新にして、別のWi-Fiやテザリングでも試しましょう。

注意：スマホを買い替える前に

スマホを買い替える前には、必ずインポートを済ませてください。前のスマホが使えなくなると、グラスに残った写真を取り出せなくなることがあります。
